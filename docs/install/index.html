Install

러스트의 rustup에 해당하는 설치기가 FreeLang에는 없습니다. 컴파일러 저장소를 받아서 CLI로 실행합니다.

1. 저장소

terminal
git clone https://github.com/kimjindol2025/freelang-v11.git
cd freelang-v11

2. 첫 실행

HTTP·DB가 있는 앱은 네이티브 바이너리가 아니라 CLI로 돕니다.

terminal
node scripts/fl-cli.js run examples/hello.fl

기대 출력:

stdout
Hello from FL!
6

3. 도구 두 개

scripts/fl-cli.js — 앱 실행. run serve repl compile만 허용합니다.

bin/fl — 네이티브 컴파일러입니다. 앱 실행 명령이 아닙니다.

4. 아직 없는 것

네이티브 fl-repl / fl-serve는 없습니다. HTTPS는 없습니다. 옛 node bootstrap.js와 npm 설치는 legacy/입니다. 버전 관리 도구(rustup 같은 것)는 없습니다. 업데이트는 저장소를 다시 받는 것입니다.
