Install

러스트 Install은 rustup 한 줄입니다. FreeLang은 컴파일러를 받아서 gcc로 직접 빌드합니다. 설치기가 숨기지 않습니다.

브라우저에서 돌려 보고 싶으면 Playground에서 예제를 읽으십시오. 실행은 이 페이지의 설치 다음입니다.

필요한 것

  • git
  • gcc
  • 개발 헤더: libsqlite3, libssl, libcurl

node, npm, sudo는 쓰지 않습니다.

설치

홍보 저장소를 받고 scripts/install.sh를 실행합니다. 기본 위치는 ~/.freelang입니다.

terminal
git clone https://github.com/kimjindol2025/freelang-ai
cd freelang-ai
scripts/install.sh

스크립트가 하는 일:

  1. freelang-v11-fx를 받아 검증된 커밋으로 맞춥니다. 현재 pin은 1d217f53a8aade8a288c0dcad0a1ba23b610f102입니다.
  2. bootstrap/stage0.c를 gcc로 빌드해 ~/.freelang/bin/stage0을 만듭니다.
  3. stage0이 컴파일러 소스 self/cgc-main.fl을 컴파일해 stage1 C를 만들고, 그걸 다시 gcc로 묶어 ~/.freelang/bin/flc가 됩니다.
  4. 그 flc가 같은 소스를 한 번 더 컴파일합니다. stage1.c와 stage2.c가 같아야 설치가 끝납니다.

성공하면 터미널에 stage1 == stage2 같음과 SHA-256이 나옵니다.

첫 프로그램

러스트의 cargo new + cargo run에 해당하는 명령입니다.

terminal
scripts/run.sh examples/01-variables.fl

run.sh는 .fl을 C로 바꾸고 gcc로 실행 파일을 만든 뒤 돌립니다. 예제 파일은 이렇습니다.

examples/01-variables.fl
;; 01 변수: define으로 이름을 붙이고, let으로 잠깐 쓰는 값을 만듭니다.
(define name "FreeLang")
(define year 2026)
(println name)
(println year)
(let [$a 10 $b 32]
  (println (+ $a $b)))

이름이 붙고, 덧셈이 되고, 세 줄이 인쇄되면 설치가 된 것입니다.

다음 파일

같은 명령으로 나머지 예제를 돌립니다.

terminal
scripts/run.sh examples/02-functions.fl
scripts/run.sh examples/10-cli-todo.fl
파일주제문법
01-variables.fl변수define, let
02-functions.fl함수defn, str
03-conditions.fl조건if, cond
04-loops.fl반복loop, recur, 재귀
05-strings.fl문자열길이, 자르기, 나누기
06-collections.fl컬렉션벡터, 맵
07-higher-order.fl고차 함수map, filter, reduce
08-errors.fl오류try, catch, throw
09-files.fl파일쓰기, 읽기, 지우기
10-cli-todo.fl작은 프로그램할 일 목록

업데이트

러스트의 rustup update 자리입니다. 저장소를 받고 설치 스크립트를 다시 실행합니다. pin 커밋이 바뀌면 새 컴파일러가 내려옵니다.

terminal
cd freelang-ai
git pull
scripts/install.sh

제거

러스트의 rustup self uninstall 자리입니다.

terminal
rm -rf ~/.freelang

홍보 저장소 폴더 자체는 따로 지우면 됩니다.

PATH

도구는 ~/.freelang/bin/flc에 있습니다. 예제 실행은 PATH에 넣지 않아도 scripts/run.sh가 그 경로를 찾습니다. 직접 컴파일하려면 그 바이너리를 부르면 됩니다.
