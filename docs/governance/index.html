Governance

러스트는 RFC로 큰 결정을 열고, 리더십 카운슬과 compiler·lang·library·infra·moderation 팀이 나뉩니다. FreeLang은 그 팀 구조가 없습니다. 대신 저장소 역할이 나뉘어 있습니다.

세 저장소

저장소역할
freelang-ai공개 얼굴. README, 예제, install.sh, run.sh, 이 사이트. 컴파일러 소스는 두지 않습니다.
freelang-v11-fx네이티브 컴파일러. stage0부터 자기 자신을 컴파일합니다. install.sh가 pin 커밋을 받습니다.
freelang-v11언어 계약과 라이브러리 문서. HTTP·fs·str·시험의 README가 여기 있습니다.

무엇이 공식 빌드인가

scripts/install.sh 안의 FL_PIN이 지금 권장하는 컴파일러 커밋입니다. pin을 바꾸면 설치기가 다른 컴파일러를 빌드합니다. 그 변경은 홍보 저장소의 스크립트 커밋으로 드러납니다.

언어 변경

문법과 런타임 패치는 v11 / v11-fx에 넣습니다. 예제와 문장만 고치면 freelang-ai에 넣습니다. 공개 RFC 게시판은 없습니다. 제안은 GitHub 이슈로 남깁니다.

Community에서 Users와 Internals가 갈라집니다.

FreeLang사람이 읽고, 모델이 쓰는 Lisp. 컴파일러가 자기 자신을 다시 컴파일합니다.
