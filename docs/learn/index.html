Learn

러스트 Learn은 책, By Example, Rustlings 세 갈래입니다. FreeLang은 아직 수백 쪽 책이 없습니다. 그 세 칸을 설치 가이드, 예제 10개, 내 기계에서 실행으로 채웁니다.

Getting started

컴파일러를 빌드하고 첫 파일을 실행합니다. 러스트 rustup + cargo new의 자리입니다.
