Playground

러스트 Playground는 브라우저에서 rustc가 돕니다. FreeLang은 브라우저에 컴파일러를 올리지 않았습니다. 이 페이지는 Rust By Example처럼 코드를 보여 주고, 실행 명령만 적습니다. 돌리려면 Install이 필요합니다.

01-variables.fl · 변수 · define, let

examples/01-variables.fl
;; 01 변수: define으로 이름을 붙이고, let으로 잠깐 쓰는 값을 만듭니다.
(define name "FreeLang")
(define year 2026)
(println name)
(println year)
(let [$a 10 $b 32]
  (println (+ $a $b)))

이 파일을 실행

terminal
scripts/run.sh examples/01-variables.fl

컴파일러가 없으면 먼저:

terminal
git clone https://github.com/kimjindol2025/freelang-ai
cd freelang-ai
scripts/install.sh
FreeLang사람이 읽고, 모델이 쓰는 Lisp. 컴파일러가 자기 자신을 다시 컴파일합니다.
