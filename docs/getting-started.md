# Getting started

Rust’s front door is Install → first `cargo run`. FreeLang’s is the same shape.

```bash
git clone https://github.com/kimjindol2025/freelang-ai
cd freelang-ai
scripts/install.sh
scripts/run.sh examples/01-variables.fl
```

Needs `git`, `gcc`, and libsqlite3 / libssl / libcurl headers. No node, no sudo.

Then read the ten examples, or open the site:

- https://g-freelang.akl.kr/install/
- https://g-freelang.akl.kr/learn/
- https://g-freelang.akl.kr/playground/
