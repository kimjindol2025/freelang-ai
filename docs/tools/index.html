Tools

러스트 Tools는 에디터, Cargo, rustfmt, Clippy, cargo doc입니다. FreeLang은 그 묶음이 없습니다. 있는 도구만 적습니다.

실행기

node scripts/fl-cli.js — 작업 디렉터리를 유지한 채 run, serve, repl, compile만 받습니다. HTTP·DB 앱은 이 경로입니다.

컴파일러

bin/fl — 네이티브 컴파일러. 앱 실행에 쓰지 않습니다.

시험

컴파일러 저장소의 시험 41/41, 감사 44/44. 러스트의 cargo test에 해당하는 통합 명령은 이 홍보 사이트에 없습니다. 저장소 README를 따릅니다.

없는 것

패키지 레지스트리(crates.io), 포맷터, 린터, 언어 서버, 에디터 공식 플러그인은 아직 이 사이트의 범위가 아닙니다.
