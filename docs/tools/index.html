Tools

지금 쓰는 도구는 설치 스크립트, 실행 스크립트, 네이티브 컴파일러 flc, 그리고 gcc입니다. 첫 실행은 node 없는 길입니다.

첫 실행

Install과 같은 경로입니다. git과 gcc가 있으면 됩니다.

terminal
git clone https://github.com/kimjindol2025/freelang-ai
cd freelang-ai
scripts/install.sh
scripts/run.sh examples/01-variables.fl

HTTP·DB 앱은 아직 node가 필요합니다. 그 안내는 Install의 「HTTP·DB 앱 실행」칸에 있습니다.

install.sh

컴파일러를 받아 세 단계로 빌드하고, 자기 자신을 다시 컴파일해 결과가 같은지 검사합니다. node와 sudo를 호출하지 않습니다. pin 커밋은 1d217f53a8aade8a288c0dcad0a1ba23b610f102입니다.

scripts/install.sh
#!/usr/bin/env bash
# install.sh — FreeLang FX 컴파일러를 받아서 직접 빌드합니다. (node·sudo 필요 없음)
# 필요: git, gcc, 그리고 libsqlite3 / libssl / libcurl 개발 헤더
# 사용법: scripts/install.sh            (기본 위치: ~/.freelang)
set -Eeuo pipefail
FL_HOME="${FL_HOME:-$HOME/.freelang}"
REPO="https://github.com/kimjindol2025/freelang-v11-fx"
PIN="${FL_PIN:-1d217f53a8aade8a288c0dcad0a1ba23b610f102}"   # 2026-11-03 자체 컴파일 검증을 한 커밋
FX="$FL_HOME/freelang-v11-fx"
mkdir -p "$FL_HOME/bin"
if [[ ! -d "$FX/.git" ]]; then git clone "$REPO" "$FX"; fi
git -C "$FX" fetch -q origin
git -C "$FX" checkout -q "$PIN"

전체 스크립트: scripts/install.sh

run.sh

.fl → C → gcc → 실행. 임시 디렉터리에서 빌드하고 지웁니다.

scripts/run.sh
#!/usr/bin/env bash
# run.sh — FreeLang 파일 하나를 C로 바꾸고, 빌드하고, 실행합니다.
# 사용법: scripts/run.sh examples/01-variables.fl
# 먼저 scripts/install.sh 로 컴파일러를 준비하세요.
set -Eeuo pipefail
SRC="${1:?사용법: scripts/run.sh <파일.fl>}"
FL_HOME="${FL_HOME:-$HOME/.freelang}"
FX="$FL_HOME/freelang-v11-fx"
FLC="$FL_HOME/bin/flc"
[[ -x "$FLC" ]] || { echo "컴파일러가 없어요. 먼저 scripts/install.sh 를 실행하세요." >&2; exit 1; }
WORK="$(mktemp -d "${TMPDIR:-/tmp}/fl-run.XXXXXX")"
trap 'rm -rf -- "$WORK"' EXIT
"$FLC" "$SRC" "$WORK/out.c" >/dev/null
gcc -O2 -w -I "$FX/runtime" $(cat "$FL_HOME/cflags") -o "$WORK/app" "$WORK/out.c" \
  $(cat "$FL_HOME/app-srcs") $(cat "$FL_HOME/ldflags")
"$WORK/app"

flc

설치 후 경로는 ~/.freelang/bin/flc입니다. FreeLang 소스를 C로 바꿉니다. 이 바이너리 자체가 FreeLang으로 컴파일된 컴파일러입니다.

자체 컴파일 증거

저장소 freelang-v11-fx에서 stage1 = stage2 = stage3입니다.

SHA-256

stage2.c  aa8bed315d2bae91630fcff72d7edcafb9afafd84dc357133bb271c3d1bda4fd
stage3.c  aa8bed315d2bae91630fcff72d7edcafb9afafd84dc357133bb271c3d1bda4fd
