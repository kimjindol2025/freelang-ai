Funding

러스트는 Foundation, 기업 멤버, 기여자 펀드가 있습니다. FreeLang은 재단 법인이 없고, 이 페이지에 다른 회사 로고를 붙이지 않습니다.

라이선스

공개 코드는 MIT입니다. 컴파일러와 예제를 받아 쓰고, 고치고, 재배포할 수 있습니다.

이 사이트를 돌리는 비용

페이지는 정적 파일입니다. 컴파일러 빌드는 사용자 기계의 gcc와 공개 GitHub 트래픽입니다. 클라우드 런타임 과금 창구를 열지 않았습니다.

후원

기부 링크, Open Collective, 재단 멤버십을 아직 만들지 않았습니다. 생기면 이 페이지에 계좌가 아니라 공개 주소와 용도를 적습니다.

FreeLang사람이 읽고, 모델이 쓰는 Lisp. 컴파일러가 자기 자신을 다시 컴파일합니다.
